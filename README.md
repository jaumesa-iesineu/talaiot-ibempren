# talaiot-ibempren

Web del projecte Talaiot per a IBEmpren (Projecte Intermodular, DAM).

Cada push a `main` es publica a https://talaiot.eu/ibempren/

## Blog

Per fer un post: crea `blog/AAAA-MM-DD-nom/` amb `titol.txt`, `data.txt` i `index.html`, i fes push. La llista de l'inici s'actualitza sola.
