Subdomini, repositori i GitHub Actions

28/10/2026

Ahir vam crear el subdomini ibempren.talaiot.eu. A més, hem configurat el repositori de GitHub perquè vagi directe al nostre servidor. Això vol dir que, quan fem push a main, la web s'actualitza sola.

Com col·laborem

  1. Canviem els fitxers al nostre ordinador.
  2. Fem commit i push a main.
  3. El servidor rep els canvis i publica la web.
Consell: abans de començar a treballar, fes sempre git pull per tenir la versió més nova.

Què fa GitHub Actions?

GitHub Actions és una petita tasca que GitHub executa cada cop que hi ha canvis. En el nostre cas, quan algú afegeix un post nou, regenera la llista de l'inici. Així ningú ha de fer res a mà.
