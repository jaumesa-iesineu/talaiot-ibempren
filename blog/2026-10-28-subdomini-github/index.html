Subdomini, repositori i GitHub Actions

29/10/2026

Aquesta setmana hem fet una passa important en la infraestructura digital de TalAIot: hem creat el subdomini oficial ibempren.talaiot.eu i hem configurat el nostre flux de treball automatitzat mitjançant GitHub i GitHub Actions.

Com col·laborem dins l'equip

Per garantir que tots els membres de l'equip puguin aportar canvis de manera àgil i sense conflictes, hem establert un protocol basat en Git:

  1. Desenvolupament local: Editem i provem els fitxers directament al nostre ordinador.
  2. Publicació: Fem commit dels canvis i fem push cap a la branca principal main.
  3. Desplegament automàtic: El servidor de producció sincronitza els continguts de manera instantània.
Consell per a l'equip: Abans de començar qualsevol tasca, cal executar sempre git pull per treballar sobre la versió més recent i evitar divergències a la branca principal.

Automatització amb GitHub Actions

Hem afegit un flux de treball automatitzat (workflow) que s'executa a cada nou push. Quan qualsevol membre publica una entrada a la carpeta blog/, un script en Python (tools/build_blog.py) regenera l'arxiu index.html de l'arrel amb la llista cronològica actualitzada, assegurant que la pàgina principal estigui sempre al dia sense intervenció manual.

Propers passos

Amb la infraestructura d'allotjament i integració contínua operativa, ens centrarem en definir el protocol de seguretat de les gravacions d'examen i les recompenses ètiques per a les proves pilot.
